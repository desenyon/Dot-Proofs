## Queue

1. **Collatz conjecture.** For every integer n ≥ 1, there exists an integer k ≥ 0 such that C^k(n) = 1, where C(n) = n/2 for even n and 3n + 1 for odd n. Standard (unaccelerated) map only. [Tao, Forum of Mathematics, Pi 10 (2022), e12](https://doi.org/10.1017/fmp.2022.8). Tao's theorem gives, for each f(n) tending to infinity, min_k C^k(n) < f(n) for a logarithmic-density-one set of n; this neither fixes the target to 1 nor handles every n. [Bařina (2025)](https://doi.org/10.1007/s11227-025-07337-0) reports finite verification for n < 2^71. No accepted universal proof identified. Status: open.
2. **Erdős–Straus conjecture.** For every integer n ≥ 2 there are positive integers x,y,z, not required to be distinct, with 4/n = 1/x + 1/y + 1/z. For Lean use the cross-multiplied equality 4xyz = n(xy+xz+yz), with positivity preserved. [Salez (2014)](https://arxiv.org/abs/1406.6307) describes a modular sieve and finite checking through 10^17; this is not modular coverage of all inputs. Status: open in sources checked. At stage 2 reconstruct prime reduction from its scaling witnesses; then test which residual classes the sieve leaves and check later reports before claiming a best bound.
3. **Hadwiger's exact coloring conjecture.** For every integer t ≥ 1 and every finite simple undirected graph G with no K_t minor, G has a proper vertex coloring using at most t−1 colors. A minor permits vertex/edge deletions and edge contractions; do not substitute topological minors or list coloring. [Delcourt–Postle](https://arxiv.org/abs/2108.01633) gives O(t log log t) coloring, not exact t−1. Review [September 2026 update](https://arxiv.org/abs/2609.06867) and [October 2026 list variant](https://arxiv.org/abs/2610.01946) before recording current best bounds; the linear list variant is not equivalent. Status: no accepted exact general result identified. At stage 3 reconstruct the complete-branch-set minor definition and check the exact small-t frontier against the original citations.

## Stage 1, entry 1: bounded descent obstruction

For q ≥ 1, the first three steps from 4q+1 are 12q+4, 6q+2, and 3q+1 < 4q+1. This excludes that residue as the least counterexample. The initial attempt to generalize to a uniform time-to-first-descent fails. In fact, for an integer B ≥ 1, take x = 2^(B+1)−1. At even times 2j for 0 ≤ j ≤ B, the orbit equals 3^j·2^(B+1−j)−1. Inductively the displayed value is odd for j < B, so two ordinary steps give (3y+1)/2 = 3^(j+1)·2^(B−j)−1; the intervening odd-time value 3y+1 exceeds y. The even-time values strictly increase, since y becomes (3y+1)/2. Therefore no time 1 through 2B descends below x. This refutes a uniform bound on first descent, not Collatz. The finite script tested q ≤ 4096 and B ≤ 512 without contradiction, and n=27 demonstrates failure within 20 steps.
